Search schedules

Each profile is a saved job survey with its own role, sites, and run time. Enabled profiles run automatically at their scheduled time; any can be run now (ADR-0005). {{ icon('settings') }}Run settings

Each profile can also carry its own filter rules. They apply in addition to the title patterns on the settings page, never instead of them, and exclude always beats include. A posting found by more than one profile is kept if any one of them would keep it, and a profile with an empty experience box never hides anything on seniority grounds. Rule changes reach postings already collected once you run filter --all; nothing is re-collected.
